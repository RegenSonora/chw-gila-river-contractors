# 0022 — CHW Gila River Contractors: a third copy, and its icon

- **Status:** Accepted by Chris, November 2, 2026
- **Spec:** SPEC §1, §2 (hosting, repo, storage, logo); follows decision 0020

## Decision

A third app, **CHW Gila River Contractors** ("Gila CHW" on the Home Screen), copied from the split point (tag `historic-0.9.0`, commit `2d65429`) the same way as Regen Time Tracking (decision 0020). It gets its own funding sources and features from here on.

| | |
|---|---|
| Repo | `RegenSonora/chw-gila-river-contractors` |
| Address | https://regensonora.github.io/chw-gila-river-contractors/ |
| Phone database | `chw-gila-river-contractors` |
| Offline cache names | `gila-<version>` (never touches `regen-` or `chw-historic-` caches) |
| Version | 0.10.0 |

**Icon:** a river valley by day. The Gila River winds through green fields (`#5fa845`, furrows `#4c8f37`) below a brown mountain range (`#8a5a3c`), with a sun (`#f6c343`) in a light sky (`#a9dbf0`); the river is `#2f7fc1`. The Android maskable icon draws the scene at 75%. It replaces decision 0017 (caduceus) for this app.

The icon uses no cultural or sacred symbols of the Gila River Indian Community (such as the Man in the Maze, the Community seal, or basket and pottery patterns). Any such element needs the Community's permission first. Showing the icon to a GRIC contact before release is recommended.

## Why

Chris asked for a version for CHW contractors working with the Gila River Indian Community. Of four options (river valley, dawn ridges, saguaro and river, river mark), Chris chose the river valley.
